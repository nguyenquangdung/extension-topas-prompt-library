# Topas Prompt Library – Chrome Extension

Topas Prompt Library là tiện ích Chrome giúp bạn **truy cập nhanh thư viện AI Prompt** trực tiếp từ trình duyệt thông qua **Side Panel**.
Bạn có thể **tìm kiếm, xem chi tiết và copy prompt** chỉ với vài click mà không cần mở website.

# 1. Chức năng chính
### 1.1. Truy cập nhanh Prompt Library
Mở thư viện prompt trực tiếp trong **Chrome Side Panel**.

### 1.2. Đăng nhập Google
Đăng nhập bằng tài khoản Google để truy cập thư viện prompt cá nhân.

### 1.3. Pin Prompt
Bạn có thể **ghim các prompt thường dùng** để truy cập nhanh.

Copy prompt chỉ với **1 click** để sử dụng trong:

# 4. Cách sử dụng

## Bước 1: Mở Extension
Click vào icon extension trên thanh công cụ Chrome.
Side Panel sẽ mở ra.

## Bước 2: Đăng nhập
Nhấn: Login with Google
Sau khi đăng nhập thành công bạn sẽ vào được thư viện prompt.

## Bước 3: Chọn Market
Ở phía trên bạn có thể chọn **Market**.

## Bước 4: Chọn Topic
Sau khi chọn market, bạn có thể lọc prompt theo **Topic**.

## Bước 5: Tìm kiếm Prompt
Sử dụng ô: Search prompts... để tìm prompt theo từ khóa.

## Bước 6: Xem chi tiết Prompt
Click vào một prompt để xem nội dung đầy đủ.

## Bước 7: Copy Prompt
Nhấn nút: Copy Prompt hoặc icon copy trên card prompt.
Sau đó paste vào AI bạn muốn sử dụng.

# 5. Ghim Prompt
Bạn có thể ghim prompt thường dùng bằng icon: 📌 Pin
Prompt sẽ xuất hiện trong mục: Pinned

# 6. Khắc phục sự cố
## Không đăng nhập được
Kiểm tra:
* Chrome có chặn popup không
* Kết nối internet
* tài khoản Google hợp lệ

## Extension không load
Thử: Reload extension tại: chrome://extensions

## Không thấy prompt
Kiểm tra:
* bạn đã được cấp quyền market?
